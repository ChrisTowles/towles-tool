The visual design language

A neutral grayscale shadcn ground where hue is a budget, spent on exactly three things: status (what an agent is doing), attention (what needs you), and identity (which repo or checkout this is). Everything else is type, spacing, and restraint.

01The three hue budgets

status

Dots mirror statusColor()

Six agent states, one dot each, defined once in lib/agentboard.ts. Never invent a seventh color — a new color implies a new state.

attention

Amber needs-you, violet focus

Amber = waiting / error / failing PRs. Violet = agent-ness and the row you're on. Amber always wins the border and fill when both apply.

identity

The identity wash

A surface that is one repo or checkout carries its hashed accent as a /10 wash — identityColor() in lib/identity-color.ts.

When adding or re-tuning any accent, check OKLab ΔE by hand against every color it can sit next to. A normal-vision ΔE under ~15 between co-occurring colors is how the yellow/amber busy bug and the orange/amber interrupted bug both shipped.

03Attention: amber wins, violet yields

session rows — idle · active (violet) · needs-you (amber)
❯ shell 1 idle
✦ refactor-vt running · 2m
✦ fix-scheduler waiting on you · 4m
  • A needs-you row gets the full treatment: border-l-2 border-l-amber-500, a row-wide bg-amber-500/10 wash, and a flag dot beside the status dot — in the same glance as the name, never stranded at the row's far edge. A thin border alone was tested and rejected: it reads as decoration, not an alert.
  • Violet marks agent-ness and the focused row (✦, active border, prompt caret). When a row is both active and needs-you, amber takes the border and fill; violet stays on the glyph. "You are here" is redundant once you're looking at it.

04The identity wash

The newest named pattern. Six literal Tailwind accents, picked by hashing a stable key, so one identity keeps its hue everywhere it appears. The wash is background, not ink — text on it stays token-colored, and status and attention render unchanged on top.

  • Key by what the surface identifies. The app header answers "which window is this" — keyed by checkout (task_label). The working-context band answers "which repo am I looking at" — keyed by repo.name. Never mix keys on one surface.
  • Absence is a state. The main checkout's header stays unwashed; a colored header means task worktree. Don't wash neutral or global surfaces.
  • Words where kind matters. The header pairs the wash with a dead-center MAIN CHECKOUT / TASK WORKTREE readout — state the fact, don't make the user decode a hue.
  • Recipe. wash = bg-<hue>-500/10 border-b-<hue>-500/40 on the surface, badge for its name chip, text for an inline readout.

05Hierarchy and the level ladder

Repo (1..N folders: clone / worktree / task) → folder (1..N sessions) → session (✦ Claude agent or ❯ zsh shell). Attention bubbles up session → folder → repo. Never flatten it, and never let a deeper level outrank its parent.

06Boxes, type, and facts

  • A box is a control or an alert, never a fact. In a rail row, facts (diff counts, branch, base-moved) are bare font-mono type; the border arrives on hover, where "is this clickable?" is the question being asked. Only needs-you, port drift, safe-to-delete and deleting keep a resting box. A pane header — one toolbar, room to spare — keeps the bordered, worded form. A surface that boxes everything ranks nothing.
  • Mono is git's voice. Branch names, +47 −53 diff stats, timestamps, counts, keyboard hints, ✦/❯, terminal content. Sans (Geist, 13px base) is the app's own voice.
  • Radius: cards/panels rounded-lg, chips/badges/tabs rounded-md, dots circular.

07Do / Don't

do

Drive every hue from statusColor(), the amber/violet rules, or identityColor(). A new color implies a new meaning — question it.

do

Use shadcn tokens, never raw colors, so light and dark both work. Tailwind + shadcn only; no hand-written CSS.

don't

Animate resting UI. animate-pulse is reserved for a live, currently-true nudge — the busy dot — never a passive fact or a rollup count.

don't

Let violet (focus) override amber (attention) on a row's edge, or restyle status dots per-identity. The budgets don't trade.
